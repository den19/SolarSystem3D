# Руководство программиста — Solar System V7

**Проект:** Solar System 3D (Unity URP)  
**Сцены сборки:** `Assets/_Scenes/MainMenu.unity`, `Assets/_Scenes/Level1.unity`  
**Скрипты:** `Assets/Scripts/` (~84 файла)  
**Версия документа:** 2026-07-16  

Документ описывает архитектуру симуляции, режимы работы, особенности, известные недостатки и направления развития. Предназначен для разработчиков, поддерживающих и расширяющих приложение.

---

## 1. Обзор архитектуры

Приложение — образовательный 3D-симулятор Солнечной системы на **Unity** (UGUI, TextMeshPro, URP). Нет единого «тика» симуляции: движение тел идёт в `Update()` через `Time.deltaTime`, глобально управляемый `Time.timeScale`.

```text
MainMenu ──► PauseAndResume (New / Continue)
                │
                ▼
             Level1
                │
                ▼
     SimulationViewBootstrap
        ├── SolarSystemScaleController
        ├── BodyOrbitSystemController
        ├── CometSystemController
        ├── OrbitLinesManager / BodyLabelManager / MinimapController
        ├── CleanViewController
        └── UI: SidePanel, TimeControl, ScaleBar, Share, Descriptions
                │
                ▼
     SimulationSessionRestorer / Autosave (PlayerPrefs)
```

Ключевые статические настройки (`*Settings`) хранятся в **PlayerPrefs** и поднимают события при изменении. UI-контроллеры подписываются на события и синхронизируют Toggle/Slider.

## 2. Механики симуляции

### 2.1. Орбиты планет и спутников

| Режим | Класс | Поведение |
|--------|--------|-----------|
| Круговые (по умолчанию) | `RotateAround` | Вращение вокруг центра с постоянной угловой скоростью (deg/s × `deltaTime`) |
| Эллиптические («Реальные орбиты») | `BodyOrbitController` | Фаза `phaseRad`, эксцентриситет и наклонение из каталога |

Переключение: `OrbitSettings.UseRealOrbits` → `BodyOrbitSystemController`.

Данные тел: `SolarSystemCatalog` — AU, радиусы (км), эксцентриситет, наклонение, орбиты спутников.

**Текущий набор тел**

- Звезда: Sun  
- Планеты: Mercury, Venus, Earth, Mars, Jupiter, Saturn, Uranus, Neptune  
- Спутники: Moon (Earth); Phobos, Deimos (Mars); Io, Europa, Ganymede, Callisto (Jupiter); Titan (Saturn); Triton (Neptune)

### 2.2. Кометы

- Каталог: `CometCatalog` — 10 периодических комет (Encke … Howell) с `simPeriodSec`.  
- Система: `CometSystemController` создаёт иерархию под `CometsRoot`.  
- Движение: `CometOrbitController`; визуал: `CometVisualController` (стадии активности).  
- Описание: `CometDescriptionPanel`.

Реальные орбиты комет включаются только если **одновременно** включены «Реальные орбиты» и «Движение комет».

### 2.3. Масштабы представления

`ScaleMode` (`ScaleSettings`):

| Значение | Смысл |
|----------|--------|
| `Educational` (0) | Сжатая учебная схема: крупные тела, короткие орбиты |
| `TrueScale` (2) | Реальные отношения орбит; размеры тел мягко сжаты (`TrueScaleSizeExponent ≈ 0.4`) |

Устаревший режим `RealDistances` (1) удалён; при чтении PlayerPrefs мигрирует в Educational.

Применение: `SolarSystemScaleController` + `SolarSystemLayout`.

### 2.4. Управление симуляционным временем

`SimulationTimeController` (статический):

- Скорость: **0.25× … 256×** (шаги ÷2 / ×2).  
- Пауза отдельно от скорости: при паузе `Time.timeScale = 0`, множитель не сбрасывается.  
- UI: `SimulationTimeControlBar` на `MainScreenCanvas` (scene + `TimeControlUiBootstrap` / `TimeControlSceneSetup`).  
- В portrait панель по центру низа; в landscape — слева внизу; учитывается safe area.

Почти вся симуляция (орбиты, кометы, showcase-камера, часть VFX) использует `Time.deltaTime` и следует `timeScale`. UI и жесты камеры опираются на `unscaledDeltaTime` / `unscaledTime`.

### 2.5. Камера и навигация

| Класс | Назначение |
|--------|------------|
| `LookAtTarget` | Фокус на теле, описание, main vs detail-камеры |
| `MobileOrbitCamera` | Orbit drag, pinch-zoom, double-tap; free observation |
| `BodyShowcaseCameraController` | Кинематографический облёт (4 оборота) → follow |
| `BodyNavigationController` / `BodyNavigationPickerController` | Prev/Next и список тел |
| `TouchInputBridge` | Enhanced Touch + fallback |

Свободное наблюдение (`UseFreeObservation`): tap по телу/комете без жёсткого guided-фрейминга.

### 2.6. Вспомогательные визуальные системы

- Линии орбит: `OrbitLinesManager`  
- Подписи тел: `BodyLabelManager`  
- Minimap: `MinimapController`  
- Гравитационная сетка: `SpacetimeGridController` + `GravityGridSettings`  
- Вид Солнца: `SunAppearanceSettings` / `SunCoronalVfxController` (Real Sun VFX)  
- Extra Graphics: `GraphicsSettings` + `PlanetTextureManager` (HD-материалы)  
- Graphics Tier (mobile): `GraphicsTierSettings` + `MobileUrpQualityApplicator`  
- Линейка масштаба: `ScaleBarController` (AU / км; tap → подсказка про а.е.)  
- Clean view: `CleanViewController` — скрывает HUD, оставляет доступ к side panel / time bar  

### 2.7. Графика на смартфонах (URP Mobile vs PC)

Android/iPhone всегда используют quality **Mobile** → [`Assets/Settings/Mobile_RPAsset.asset`](Assets/Settings/Mobile_RPAsset.asset). Standalone — **PC** → `PC_RPAsset`.

| Параметр | Balanced (mobile default) | High (mobile) | PC |
|----------|---------------------------|---------------|-----|
| Render Scale | 0.8 | 1.0 | 1.0 |
| MSAA | off (1) | 2× | 2× |
| Shadow map | 1024 | 1024 | 4096 |
| Soft shadows / SSAO | нет | нет | да (PC renderer) |

**Effective High** включается только если Extra Graphics ON **и**:

- mode = `High`, или  
- mode = `Auto` и `SystemInfo.graphicsMemorySize >= 2048`.

Иначе — Balanced. Runtime: `MobileUrpQualityApplicator` (только Android/iOS).

**«Бомбическое» Солнце на устройстве**

1. Extra Graphics ON + Real Sun ON (side panel / defaults).  
2. Graphics quality: Auto (на флагмане) или High.  
3. Сфокусировать камеру на Солнце — granulation/sunspots/flicker/CME и усиленный bloom на close zoom (`SunCoronalVfxController`).

## 3. Режимы работы и настройки

### 3.1. Поток сессии

| Режим | API | Поведение |
|--------|-----|-----------|
| New | `PauseAndResume.StartNewSimulation()` | Очистка снимка сессии; старт Level1 с дефолтами камеры/движения/времени |
| Continue | `PauseAndResume.ResumeGame()` | Восстановление камеры, фокуса, фаз орбит, скорости и паузы |
| Enter menu | `PauseAndResume.EnterMenu()` | Capture сессии → MainMenu (`timeScale = 1` для UI меню) |

Autosave: `SimulationSessionAutosave` при pause/quit приложения на Level1.

**Важно:** настройки тумблеров (орбиты, масштаб, кометы…) живут в отдельных PlayerPrefs и **не очищаются** при New — только при Reset / `SolarSystemConfigurationReset`. Сессия хранит камеру, движение и время.

### 3.2. Тумблеры Level1 (боковая панель)

| UI | Настройка | По умолчанию |
|----|-----------|--------------|
| Орбиты | `ShowOrbitLines` | вкл |
| Гравитационная сетка | `UseGravityGrid` | вкл |
| Подписи | `ShowBodyLabels` | вкл |
| Minimap | `ShowMinimap` | вкл |
| Интерфейс | `ShowSimulationUi` (выкл = clean view) | вкл |
| Схематично / Реальный масштаб | `ScaleMode` (radio) | Educational |
| Реальные орбиты | `UseRealOrbits` | выкл |
| Движение комет | `UseCometMovement` | вкл |
| Свободное наблюдение | `UseFreeObservation` | выкл |
| Реальное Солнце | `UseRealSun` | вкл |

### 3.3. MainMenu

- Продолжить / Новая симуляция  
- Язык: English, Russian, Chinese, Vietnamese, Uzbek  
- Громкость, Extra Graphics, **Graphics quality** (Auto / Balanced / High), CPU Monitor  
- About, Reset настроек  

`GraphicsTierControlController` создаёт строку Settings под Extra Graphics в runtime, если её нет в сцене.

### 3.4. Языки и локализация

- `LocalizationManager` загружает `Assets/Resources/Languages/*.json`.  
- `LocalizedText`: ключ перевода = **имя GameObject** в сцене.  
- Шрифты: `LocalizationFontHelper` (в т.ч. CJK).  

Переименование UI-объекта без обновления JSON ломает перевод.

## 4. Особенности реализации

1. **Нет физики орбит** — кинематическая интеграция угла/фазы, не N-body.  
2. **Двойная камерная модель** — Main Camera + набор detail-камер по телам; усложняет фокус и сессию.  
3. **Масштаб TrueScale** — компромисс: истинные отношения орбит, но размеры не 1:1 (иначе внутренние планеты исчезают).  
4. **TimeScale глобален** — ускорение влияет на всё, что использует `deltaTime` (включая showcase).  
5. **Scene-first UI** — панель, time bar, навбар живут на сцене; Editor menu `Solar System/Setup …` + runtime bootstrap как fallback.  
6. **Safe area** — `SafeAreaInsets` для навбара, side panel, time bar, CpuLoadMonitor, ScaleBar.  
7. **CpuLoadMonitor** в portrait поднимается над time bar (bottom-right), в landscape остаётся у нижнего правого края.  
8. **ScaleBar** — линейка расстояния на `MainScreenCanvas` (runtime через `ScaleBarController.EnsureOnCanvas`): portrait/landscape bottom-right **над CPU** (если CPU выкл — на его месте), не пересекается с minimap (левый низ) и time bar (центр/лево). Подпись в AU (`SolarSystemScaleController.AuToUnity` + `SolarSystemCatalog.AuKm`); при близком зуме — км. Tap открывает локализованную подсказку (ключи `ScaleBarAu*`). В clean view скрывается вместе с HUD.  
9. **Share** — скриншот + Android share; сообщения локализованы.  
10. **Mobile graphics tier** — High поднимает renderScale/MSAA только на устройстве; в Editor (PC quality) картинка изначально сильнее.  

Ключевые пути:

- `Assets/Scripts/SimulationTimeController.cs`  
- `Assets/Scripts/SimulationSessionState.cs`  
- `Assets/Scripts/SolarSystemGraphics/SolarSystemCatalog.cs`  
- `Assets/Scripts/SolarSystemGraphics/GraphicsTierSettings.cs`  
- `Assets/Scripts/MobileUrpQualityApplicator.cs`  
- `Assets/Scripts/SolarSystemGraphics/SunCoronalVfxController.cs`  
- `Assets/Scripts/ScaleBarController.cs`  
- `Assets/Scripts/SimulationViewBootstrap.cs`  
- `Assets/Editor/SidePanelSceneSetup.cs`, `TimeControlSceneSetup.cs`

## 5. Недостатки и технический долг

| Проблема | Комментарий |
|----------|-------------|
| Локализация по имени объекта | Хрупко при рефакторинге UI |
| Устаревший `Publish/PlanEn.txt` | Часть багов уже исправлена; план не синхронизирован с кодом |
| `AboutPanel.cs` — заглушка | Анимация через UI Samples `PanelManager` |
| `GameState.score` не используется | Задел под геймификацию |
| `Spawner` / `Projectile` | Пул есть, игрового режима slingshot нет |
| Тяжёлая иерархия detail-камер | Память / поддержка на мобильных |
| Рассинхрон комментариев clean view vs кометы | Видимость комет завязана на `UseCometMovement`, не только на UI toggle |
| Нет единой документации API каталога комет/тел | Расширение требует правок в нескольких местах (каталог, навигация, локализация, префабы описаний) |
| New vs Continue путает пользователей | Настройки тумблеров переживают New |

Исправленные ранее (не считать открытыми): raycast closest-hit, sync языка, pause через `SimulationTimeController`, скриншоты в `persistentDataPath`, time control UI, scale modes Educational/TrueScale, reset Real Sun + Graphics Tier.

## 6. Планы развития

### 6.1. Какие планеты и спутники добавить

Приоритет — образовательная ценность и узнаваемость при разумной нагрузке на мобильные GPU.

**Планеты / карликовые планеты**

1. **Плутон + Харон** — классика школьной программы, бинарная система.  
2. **Церера** — крупнейший объект пояса астероидов.  
3. **Эрида / Макемаке / Хаумеа** (опционально, упрощённо) — пояс Койпера.

**Спутники (высокий приоритет)**

| Центр | Кандидаты | Зачем |
|--------|-----------|--------|
| Saturn | **Энцелад**, Рея, Диона, Тефия | Криовулканизм, кольца в контексте |
| Uranus | **Миранда**, Титания, Оберон | Слабо представлены в приложении |
| Neptune | **Протей**, Нереида | Дополнение к Triton |
| Jupiter | **Амальтея** (опционально) | Внутренний спутник |
| Earth | — | Moon уже есть |
| Mars | — | Phobos/Deimos уже есть |

**Малые тела / структуры**

- Пояс астероидов (схематичное кольцо частиц или несколько именованных астероидов: Веста, Паллада).  
- Кольца Урана/Нептуна (упрощённые).  
- Доп. кометы: Галлея (как «длиннопериодический» учебный кейс), Чурюмова–Герасименко (67P).

**Технический чеклист добавления тела**

1. Запись в `SolarSystemCatalog` / при необходимости отдельный visual prefab.  
2. Объект на Level1 + collider для pick.  
3. `BodyNavigationOrder` + локализованные ключи.  
4. Prefab описания в `Assets/Prefabs/Descriptions/`.  
5. Detail camera (если нужен) + wiring в `LookAtTarget`.  
6. Орбита: circular и elliptical пути; orbit line; label; minimap icon.  

### 6.2. Геймификация

1. **Gravity slingshot** — запуск зонда, гравитационные манёвры около планет (задел: `Spawner`/`Projectile`).  
2. **Квиз по астрономии** — вопросы у тела («какая планета ближе к Солнцу?»), очки в `GameState.score`.  
3. **Миссии наблюдения** — «найди комету», «сфокусируйся на Энцеладе», таймер на обычной скорости.  
4. **Unlockables** — открытие описаний/скинов после правильных ответов.  
5. **Сравнение периодов** — челлендж: подобрать time scale так, чтобы Меркурий сделал N оборотов за время одного оборота Земли.  
6. **Достижения** — посетил все планеты, включил TrueScale, посмотрел комету в perihelion-визуале.  

Геймификацию держать опциональной (toggle), чтобы не ломать «чистый» образовательный режим.

### 6.3. Усиление образовательной составляющей

1. Карточки фактов: масса, период обращения, температура, число спутников — из расширенного каталога.  
2. Сравнение «если Солнце — мяч…» в Educational mode.  
3. Временна́я шкала: дата/юлианский день симуляции (сейчас только множитель скорости).  
4. Аудиогид / короткий narrator tour по телам (PlanEn).  
5. Режим «учитель»: скрыть UI, оставить time bar + крупный заголовок тела.  
6. Схема затмений / фазы Луны (упрощённо).  
7. Связь единиц: AU ↔ км на линейке масштаба (`ScaleBarController`) и в описаниях; период ↔ земные сутки — в описаниях.  
8. Локализация описаний планет полностью во всех 5 языках (проверить полноту ключей).  

### 6.4. UI / UX

1. Единый design token set (цвета/отступы) вместо разрозненных констант в bootstrap.  
2. Иконки pause/play вместо текста «II» / «>».  
3. Подсказки первого запуска (coach marks) для side panel и time bar.  
4. Явное разделение «настройки симуляции» vs «настройки сессии» в меню Continue.  
5. Адаптив: избежать наложений (CpuLoadMonitor / ScaleBar над time bar, minimap слева) для описаний и toast.  
6. Accessibility: крупные hit-area, контраст, TalkBack/VoiceOver labels (ключи уже частично есть для time control).  
7. Плавный переход New/Continue с превью сохранённого тела.  
8. Редизайн About / Settings в одном визуальном языке с Level1 HUD.  

### 6.5. Оптимизации

| Область | Идея |
|---------|------|
| Камеры | Одна orbit-камера + сдвиг target вместо N detail cameras |
| Орбиты | LOD линий орбит; отключение update далёких спутников вне фокуса |
| Кометы | Frustum / distance culling хвостов; shared materials |
| UI | Отключить raycast на декоративных Image; пул toast |
| CPU | Batch/Job для фаз орбит при большом числе тел |
| Память | Атласы текстур планет; сжатие ASTC на Android |
| Загрузка | Addressables для описаний и редких тел |
| TimeScale | При очень высоких скоростях — fixed substeps или clamp delta, чтобы не «перескакивать» орбиту |
| Профилирование | Регулярный проход Profiler на mid-range Android (целевой FPS) |
| Сборка | IL2CPP, managed stripping, отключение неиспользуемых пакетов UI Samples в релизе |
